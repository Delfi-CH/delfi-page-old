Introduction

When I was younger, I had the desire to create my own video game. This eventually lead me to go study Computer Science after 9th grade, where I am now.

At school, I am currently learning full-stack web development, primarily using ReactJS for frontends, Java SpringBoot for backends with a MariaDB Database.

I also have some experience with Python (mostly for data visualisation with matplotlib) and in writing UNIX shell scripts with GNU BASH.

During my free time, I have also started learning lower level languages like Rust and C by writing command-line programms with the eventual goal of writing desktop-applications.
